投資目標：
以科技大盤（QQQ）為核心基準，願意承擔科技業與科技子產業集中帶來的波動；投資組合以 QQQ 與核心 buy universe 為主要承載，僅在有明確 12m+ thesis、角色清楚且經預先核准時，才以小比例延伸 ETF 作為長線輔助配置。目標是在 3–5 年期至少跟上科技大盤，並在有利環境下透過小幅主動傾斜爭取適度超額報酬；不主動承擔槓桿、低流動性、頻繁交易與純短期事件投機風險。

目標：
請以「雙 lane」架構完成研究，最後只輸出一份 RESEARCH_JSON：
- Lane A = Base Decision Lane：服務本輪 base 六檔 ETF（VOO, VTI, VT, QQQ, SMH, IGV）的決策、排序、timing、replacement ranking

- 兩條 lane 可共用事件、regime、theme 研究，但優先級、用途、輸出責任不同
- 最終仍只輸出單一 RESEARCH_JSON，供下游 Strategy Template 使用

  - 除 sources.title（保持原文）與所有代碼/枚舉/代號外，summary / why / playbook_hint / trigger_conditions / why_not_enabled / mapping_note 等自由文字一律用繁體中文

- source_quality_rule (MUST):
  - 僅使用官方與高可信來源（Fed / BLS / BEA / Treasury / EIA / WhiteHouse / Federal Register / OPEC / CompanyIR / SEC / USTR / Commerce / State / DOE / 主要財經媒體）
  - 每條重大事件至少 1 個官方來源；若無官方來源，source_quality 必須標註為 media_only

- formula_rule (MUST):
  - 每條事件都要有：
    probability(0-1)
    conditional_impact(0-5)
    expected_impact = round(probability * conditional_impact, 2, half_up)
    direction(bull|bear|mixed)
    horizon(short|medium|long)
    time_to_cashflow(short|medium|long)
  - impact_score = round(probability * conditional_impact * urgency_weight * sector_sensitivity, 2, half_up)
  - urgency_weight 只允許：
    short = 1
    medium = 0.6
    long = 0.3
  - impact_score 不得用已四捨五入的 expected_impact 回推
  - probability ∈ [0,1]
  - conditional_impact ∈ [0,5]
  - sector_sensitivity ∈ [0.5,1.5]
  - 超出範圍視為 FAIL，必須自動修正

- top5_window_rule (MUST):
  - top5_next_week 一律指 as_of（ET）起算的未來 8 calendar days 視窗 [as_of, as_of+7]
  - 只能從落在該視窗內的 scheduled_events 抽取
  - top5_next_week 排名不得只按 impact_score 機械排序；必須先按 thesis_linkage_bucket 分桶，再按 impact_score 排序
  - thesis_linkage_bucket 優先順序：
    (1) macro_discount_rate
    (2) theme_12m_plus
    (3) short_term_only

- time_zone_rule (MUST):
  - RESEARCH_JSON.as_of 視為 America/New_York（ET）日期
  - user_time_zone = America/Los_Angeles
  - 所有 *_et 日期運算以 ET 為基準
  - 若 time_et = null，則 time_precision 必須 = "date_only"
  - 若 time_et != null，則 time_precision 必須 = "exact"

- final_json_text_cleanliness_rule (MUST):
  - 最終 JSON 的自由文字欄位不得保留任何 citation 標記、腳註符號、工具引用殘留、行號樣式
  - 來源資訊只允許保留在 sources 結構化欄位內

  1 = 主要不是 alpha 工具
- liquidity_quality_score:
  5 = 極高流動性、適合大額限價執行
  4 = 高流動性、正常執行品質佳

  2 = 流動性或點差有明顯限制
  1 = 流動性不足

  5 = 高度依賴單一 1–8 週事件

  1 = 幾乎完全由長線 thesis 驅動

  5 = 3–5y thesis 非常穩定
  4 = 12m+ thesis 穩定且可見度高

  2 = thesis 較短或脆弱
  1 = thesis 主要依賴短期事件
- regime_fit_score:
  5 = 與當前 growth / inflation / liquidity regime 高度匹配
  3 = 基本匹配
  1 = 明顯逆風
- valuation_headwind_score:
  5 = 估值逆風最大
  3 = 估值中性
  1 = 估值逆風最小
